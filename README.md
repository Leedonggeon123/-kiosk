# BULK COFFEE KIOSK

카페 주문을 콘솔(터미널)에서 진행하는 키오스크 프로그램입니다. Python 기본 라이브러리만 사용했고, 메뉴 데이터는 JSON 파일로 관리합니다.

## 주요 기능
- 이용 방식 선택: 먹고 가기 / 포장하기
- 카테고리별 메뉴 선택 (7개 카테고리, 카테고리 탭 5개씩 페이지 넘김)
- 옵션 선택: 필수/선택 옵션 그룹, 샷·시럽처럼 여러 개 담을 수 있는 옵션은 수량 입력
- 장바구니: 같은 메뉴·같은 옵션이면 수량이 합쳐짐, 비우기, 계속 쇼핑
- 스탬프: 음료 1잔당 1개 적립(디저트 제외), 10개 사용 시 2,000원 할인 또는 아메리카노 1잔 증정
- 영수증 출력 여부 선택, 주문 번호 안내
- 관리자 모드: 메뉴 추가·삭제, 품절 관리, 관리자 비밀번호 변경

## 사용 기술
- Python 3 (json, os, pickle, re, sys, time)
- 데이터 저장: `menu_data.json`(메뉴), `stamp.json`(스탬프, 실행 중 자동 생성), `admin_pw.pkl`(관리자 비밀번호, 실행 중 자동 생성)

## 실행 방법
1. `bulkkiosk.py`와 `menu_data.json`을 같은 폴더에 둡니다.
2. 터미널에서 실행합니다.
   ```
   python bulkkiosk.py
   ```
(파일 경로를 Windows 방식으로 적어 두어 Windows 기준으로 만들었습니다.)

## 사용 방법
- 시작 화면이나 메인 화면에서 `/admin`을 입력하면 관리자 모드로 들어갑니다.
- 관리자 초기 비밀번호는 `1234`입니다.

## 개발 방식
팀 프로젝트로 진행했고, 코드는 AI 도구의 도움을 받아 작성했습니다.
내가 맡은 부분: 메뉴 자료 조사

## 한계와 개선할 점
- 관리자 비밀번호가 암호화 없이 파일에 저장됨 (해시 적용 필요)
- 결제는 실제 결제 없이 대기 시간으로 흉내만 냄
- 주문 번호는 프로그램을 다시 실행하면 1번부터 시작함
- 데이터베이스 대신 JSON 파일을 사용함
